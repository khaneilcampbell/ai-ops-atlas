# Final Resume Quality Checklist

Complete before approving any tailored resume. Every box must be checked.

## Accuracy
- [ ] Every bullet traces to an entry in the career database
- [ ] Titles, employers and dates match `experience.json` exactly
- [ ] No invented metrics, tools, or responsibilities
- [ ] Independent projects are labelled as projects, not employment
- [ ] All `[CONFIRM: ...]` flags resolved or removed

## ATS readability
- [ ] Single column; no tables, text boxes, images, or icons
- [ ] Standard headings (Summary, Experience, Projects, Skills, Education, Certifications)
- [ ] Contact info in the body, not in the header/footer
- [ ] Keywords appear naturally and are supported by experience
- [ ] Saved as DOCX and PDF with selectable text

## Writing
- [ ] Spelling and grammar checked
- [ ] Past tense for past roles, present tense for the current role
- [ ] Bullets start with strong verbs; no "responsible for"
- [ ] No generic AI phrasing ("leveraged cutting-edge synergies")
- [ ] One page preferred, two maximum

## Fit
- [ ] Summary speaks to this role's top competencies
- [ ] Most relevant experience and projects appear first
- [ ] Sections that already fit were left alone

## Admin
- [ ] File named `FirstName_LastName_Company_Position_Resume`
- [ ] Saved to `private/applications/<company>-<position>/`
- [ ] Tracker row added or updated
