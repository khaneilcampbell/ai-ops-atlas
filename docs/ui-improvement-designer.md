# AI UI Improvement Designer

Atlas-owned specialist who works from Atlas HQ (its Model Lab suite left with the Skyline district on November 8, 2026). Select the agent and copy its Claude Code review prompt to request a focused design review. Supply current screenshots and a small scope (for example map labels or lobby navigation).

The agent is idle until explicitly requested. It returns at most three evidence-backed recommendations and does not modify code. Existing model-free system-improvement reports and CI evidence are reused: this registration creates no extra scheduled jobs, API calls, or model runs. Manual Claude Code reviews use account allowance. No review has been started as part of setup.

Review instructions: `ops/system-improvements/ui-design-prompt.md`. Implementation and merging require a separate request.
