# Agent and automation organization

The catalog previously grouped class B (AI-assisted workflows) with class A agents. The documented class B definition describes predefined steps containing a model call, not an independent agent. A title such as “Coordinator”, an n8n runtime, or use of a model alone does not change the declared classification.

## Shared directory rule

| Directory | Existing classifications | Count |
| --- | --- | --- |
| Agents | A: AI agent; F: explicitly planned agent | 16 (15 A, 1 F) |
| Automations | B: AI-assisted workflow; C: deterministic automation; D: CI/CD; E: utility/integration | 41 |

Thirteen class B entries move to Automations: Atlas's five improvement/review/coordinator workflows, Benjaire intake, three career drafting/review workflows, three GitHub workflows, and product visualization. All catalog IDs, declared classifications, project/repository ownership, workplace declarations, source references and observed records are unchanged. No workflows are activated. Planned and observed execution status remain separate from directory membership.

The same helper drives directories, organization records, map counts and simulated agent workdays. Fixed workflows no longer receive an AI-agent commute. Existing workflow workspace declarations remain available in the catalog; a workstation is not execution evidence.

Saved type filters incompatible with the new directory are cleared. The Output interface remains available for automations. Regression checks cover every class, representative real entries, an exhaustive identity-preserving partition, simulated commute identities, the agent Workday tab, directory counts and Output access on desktop and phone.

Screenshots in this folder show before/after directory views. Full CI screenshot comparisons may require separate review because the map's intended inventory counts change; no baselines or tolerances are changed here.

## Validation

1,000 unit tests, type checks, lint and build passed. Three final browser checks passed (desktop/phone directories and agent Workday). Desktop and phone directory checks verify 16 agent entries and 41 automation entries, cleared legacy filters, preserved IDs, Output access and no horizontal overflow. Before/after screenshots were reviewed. No operational services, schedules or integrations were activated.

Mission Control and repository/grid inventories label mixed populations as Agents & automations and expose their separate counts. Inspector labels use the same classification.
