# skyline

Skyline residential district and branded retail spaces for AI Ops Atlas.

## Atlas connection

This private repository is tracked by [AI Ops Atlas](https://github.com/khaneilcampbell/ai-ops-atlas) as `khaneilcampbell/skyline`. Its project registration is maintained in `catalog/skyline.yaml` in Atlas.

Building models, apartment floors, lobby, floor navigation, lighting, and city routes currently live in the `ai-ops-atlas` repository. Keep district plans and future Skyline-specific implementation here.

## Live status

Atlas reads actual GitHub repository data when its GitHub connection has access to this private repository. A repository connection does not automatically create agents or business integrations.

## Agents and businesses

No Skyline workers are registered yet. Interior occupants and company-branded buildings are visualizations. Register real agents in Atlas once their purpose, source, and runtime are documented.
