# Security Policy

## Supported versions

Only the latest version on `main` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through [GitHub private vulnerability reporting](https://github.com/khancam15/Service-Desk-Intelligence-Dashboard/security/advisories/new). Include:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept
- Affected files, endpoints or versions

You can expect an acknowledgement within 3 business days and a status update within 10 business days.

## Handling of data

This project processes service desk data that may include personal information. Production ticket data must never be committed to the repository, attached to issues, or used in test fixtures.
